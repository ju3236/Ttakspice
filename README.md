# Ttakspice

우리 창작 세계관(SCP 재단 같은 이상 개체 격리 조직)을 배경으로 한 **격리 시설 관리 시뮬레이션** 게임.
직원을 개체에 배치해 작업하고, 데이터를 모아 하루 할당량을 채우고, 격리가 실패하면 진압해야 한다.

> 장르에서 영감을 받은 오리지널 게임입니다. 개체·용어·시스템은 우리 세계관 기준으로 새로 만듭니다.

## 실행

빌드 과정 없음. 정적 서버로 열기만 하면 됨 (ES 모듈이라 `file://` 로 직접 열면 안 됨).

```bash
python3 -m http.server 8000
```

그리고 브라우저에서 http://localhost:8000 접속.
GitHub Pages(Settings → Pages → main 브랜치)를 켜면 링크 하나로 친구한테 공유 가능.

## 플레이 방법

시설 단면도에서 직원들이 복도와 엘리베이터를 걸어 다니며 일함. 맵은 드래그로 이동, 휠/핀치로 확대.

1. 오른쪽 아래 명단이나 맵에서 **직원을 클릭**해 선택 (선택 안 하면 대기 중인 직원이 자동 배정)
2. **격리실을 클릭** → 오른쪽 패널에서 **작업 종류**(관측 / 관리 / 교감 / 통제) 선택
3. 직원이 격리실까지 걸어가서 작업. 결과 `좋음 / 보통 / 나쁨` 에 따라 **안정도**(격리실 오른쪽 칸)가 오르내림. 0이 되면 **탈출**
4. 탈출한 개체는 시설을 돌아다니며 직원을 공격함. 개체를 클릭해서 **진압 투입**
5. 작업 중 성공할 때마다 데이터 큐브가 할당량으로 날아감. 실패하면 직원이 피해를 입음
6. **긴급 작업 경보**: 할당량 30% / 60% / 90% 에서 격리실에 경보가 걸림. 시간 안에 그 개체를 작업하지 않으면 안정도 감소
7. **성장**: 관측→집중, 관리→근성, 교감→침착, 통제→기민 경험치가 쌓여 능력치가 오름
8. **장비 추출**: 개체를 작업하면 그 개체의 에너지가 쌓임. 격리실 패널에서 무기/방호복을 추출해 직원 패널에서 지급
9. **지원 조치**: 직원 패널에서 응급 치료(체력) / 진정 처치(정신력, 패닉 해제). 하루 2회씩
10. 연구(작업 횟수)를 끝까지 하면 그 개체 작업 성공률 +5%
11. 할당량을 채우면 **업무 종료** → 새 개체 수용, 직원 강화·채용
12. 작업을 반복하면 개체의 **문서**(선호 작업, 특이사항, 설정)가 해금됨

단축키: `Space` 일시정지, `1` `2` `3` 배속, `Esc` 문서 닫기

## 세계관 넣는 법 (여기만 고치면 됨)

| 파일 | 내용 |
|---|---|
| `src/data/entities.js` | **개체 목록**. 하나 추가하면 바로 게임에 등장 |
| `src/data/config.js` | 조직/시설 이름, 위험 등급 체계, 작업 종류, 직원 이름, 밸런스 수치 |
| `docs/WORLDBUILDING.md` | 세계관 설정 정리용 문서 (게임에는 영향 없음) |

### 직원 꾸미기 (게임 안에서)

- 직원을 선택 → 오른쪽 패널 **✎ 꾸미기**: 이름, 이미지, 이름표 색, 메모 변경
- 하루 끝 **직원 채용**: 채용 전에 이름·이미지를 정하고 능력치를 다시 뽑을 수 있음
- **업로드** 버튼으로 이미지를 바로 올릴 수 있음. 투명 여백은 자동으로 잘림
- 업로드한 이미지는 **그 브라우저에만** 저장됨 (새 게임을 해도 남아 있음). 친구도 보게 하려면 아래처럼 저장소에 넣기

### 이미지 넣기 (저장소에 고정)

- 직원 편집 화면의 기본 이미지 목록: `config.js` 의 `STAFF_IMAGE_PRESETS` 에 경로 추가
- 처음부터 등장하는 고정 직원: `assets/staff/` 에 PNG 넣고 `config.js` 의 `STAFF_ROSTER` 에 `{ name: "이름", image: "assets/staff/파일.png" }` 추가
- 개체: `assets/entities/` 에 PNG 넣고 `entities.js` 의 개체에 `image: "assets/entities/파일.png"` 추가
- 이미지가 없으면 기본 이미지(`assets/staff/default.png`, `assets/entities/placeholder.png`) 사용
- **투명 배경 PNG**, 캐릭터 주변 여백은 잘라내기 (발이 이미지 맨 아래에 닿게)

개체 작성 템플릿은 [`docs/WORLDBUILDING.md`](docs/WORLDBUILDING.md) 참고.

## 구조

```
index.html          화면 틀
style.css           스타일
src/main.js         렌더링 / 입력 처리 / 카메라
src/game.js         게임 규칙 (이동, 작업, 안정도, 탈출, 진압, 하루 진행, 저장)
src/layout.js       시설 배치 (층, 격리실, 복도, 엘리베이터 좌표)
assets/             캐릭터 이미지
src/data/           세계관 데이터
```

진행 상황은 브라우저 localStorage에 자동 저장됨.
